# 화면 구현 참고 (Todo 항목 아님)

화면을 만들 때는 사용자가 보낸 참고 이미지(`.claude/design-reference.jpg`, 다른 서비스 화면이라 저장소에 올리지 않음)의 **구성과 분위기만** 따른다. 그 서비스의 이름·로고·사진은 쓰지 않는다.

- 분위기: 흰 배경, 연보라(라벤더) 포인트 색 하나, 둥근 모서리, 사진이 큰 카드, 모바일 우선
- 첫 화면: 큰 제목("어디로 떠날까요?"), 포인트 색 테두리 검색창 + 돋보기 버튼, 옆으로 넘기는 큰 사진 카드(인기 도시), 지역 칩 격자, 해시태그 칩(장소 종류), 2열 사진 카드와 포인트 색 `[도시]` 표기
- 장소 상세: 위쪽 큰 사진, 이름, 주소 + 거리 배지, 따옴표로 감싼 한 줄 소개, 정보 태그 칩, 둥근 테두리 카드 안의 설명
- 목록 화면: 상단 뒤로가기 + 가운데 제목, 해시태그 제목, 2열 사진 카드

## 페이지 구성 (사용자가 보낸 두 번째 참고 이미지, `.claude/layout-reference.png`, 저장소에 올리지 않음)
한 화면에 모든 기능을 길게 늘어놓지 않고, 비슷한 기능끼리 페이지로 묶는다. 이미지의 서비스 이름·로고·사진은 쓰지 않는다.

- 위쪽 고정 메뉴: 로고 + 홈 · 여행지 · 내 여행 + 오른쪽 "여행 만들기" 버튼
- 홈: 큰 히어로 카드(제목·검색·버튼), 화살표로 넘기는 인기 여행지 카드, 가운데 "이렇게 준비해요" 단계 카드(눌러서 해당 페이지로 이동), 다가오는 여행
- 여행지: 검색, 지역 칩, 도시 카드 목록
- 도시: 탭(소개·항공권 / 명소 / 식당·카페) + "이 도시로 여행 만들기"
- 내 여행: 다가오는 여행 / 다녀온 여행 목록
- 여행: 탭(한눈에 / 가고 싶은 곳 / 준비물 / 메모 / 둘러보기, 4단계에서 예산 탭 추가)
- 주소(#/...)로 페이지를 나눠 브라우저 뒤로 가기가 동작하게 한다
